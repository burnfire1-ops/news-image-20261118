# News Image — 18 November 2026 (50 cerita)

Satu halaman gambar yang merangkum berita dunia pada Rabu, 18 November 2026:
50 cerita dari 6 benua, disusun dalam satu tata letak yang bisa dibaca sekilas
sebagai gambaran hari itu di seluruh dunia.

Tata letak: 2 lead dengan ilustrasi besar, 8 Tier A dengan ilustrasi spot,
peta dunia dengan pin bernomor, dan 40 brief dalam daftar dua kolom.

## Menjalankan

Program ini hanya menyalin gambar final (`entry.png`) ke direktori output.

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Hasilnya: `entry.png` di dalam direktori output tersebut, identik dengan
gambar di repo ini. Kalau `MAKEFUN_OUTPUT_DIR` tidak disetel, program memakai
`/output`.

Catatan: `entry.png` saat ini masih gambar placeholder dari kit starter.
Gambar ini akan diganti dengan artwork 50 cerita yang sudah disetujui,
setelah tesis (Rev 2) disetujui dan entrinya diimplementasikan.
